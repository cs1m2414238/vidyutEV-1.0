# Vidyut Web

React + TypeScript + Vite client for the Vidyut EV charging platform.

```powershell
npm install
npm run dev
```

Set `VITE_API_BASE_URL` when the backend is not available at
`http://localhost:8080/api`. See `.env.example`.

Validation commands:

```powershell
npm run build
npm run lint
```
